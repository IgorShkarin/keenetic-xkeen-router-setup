# Что направляется напрямую

Импорт профиля на iPhone подтверждён экранами 18 октября, 22:06;
работа правил на живом трафике ещё не проверена. Названия ниже — примеры
из российских списков и проверенных доменов, а не обещание полного покрытия
каждого стороннего запроса приложения.

| Группа | Примеры |
|---|---|
| Банки и платежи | Сбер, Т-Банк, Альфа-Банк, ВТБ, Райффайзен, Газпромбанк, МТС Банк, ПСБ, Россельхозбанк, Уралсиб, банк «Санкт-Петербург», Точка, НСПК/СБП, Best2Pay, Корона |
| Покупки | Ozon, Wildberries, Авито, Циан, Юла, Лемана ПРО, DNS, М.Видео, Эльдорадо, Детский мир, Lamoda; российский домен AliExpress |
| Продукты и доставка | ВкусВилл, Пятёрочка, Перекрёсток, Магнит, Лента, Купер, Додо, СДЭК, Почта России |
| Госуслуги | Госуслуги, ФНС, mos.ru, региональные порталы |
| Здоровье | Поликлиника.ру, Зуб.ру, ЕМИАС, МЕДСИ, Аптека.ру и другие российские медицинские сайты |
| Видео и развлечения | Кинопоиск, Иви, Okko, Wink, Rutube, Start |
| Карты и транспорт | Яндекс Карты/Go, 2ГИС, РЖД, Туту, Авиасейлс, Островок, Ситидрайв |
| Связь и почта | МТС, МегаФон, Билайн, T2, Ростелеком, Дом.ру, Mail.ru, VK, Одноклассники |
| Работа и сервисы | HeadHunter, Контур и российские компании из базы |
| Другие категории | Образование, российские СМИ, форумы, медицина, ИИ-сервисы и технические издания |

Основа — [category-ru](https://github.com/v2fly/domain-list-community/blob/6b0f8edc935ee0ad2cb386ac3efd451ee2380ac5/data/category-ru),
включая 13 тематических подкатегорий и 81 исходный файл по дереву включений.
Российские зоны, включая `.ru`, `.su`, `.рф` и `.moscow`, входят через `tld-ru`.
Дополнительно российские IP направляются напрямую по `geoip:ru`.
Приоритет имеют перечисленные в профиле исключения VPN.

Семейства Ozon, `kinopoisk.ru`, `polyclinika.ru` и `zub.ru` также
добавлены явно. Российские приложения, различимые на присланных экранах,
учтены в примерах; неоднозначным значкам названия не приписывались.
Bybit и OKX проверены как зарубежные домены и используют общий выход VPN.

Полный перечень 110 проверенных доменов и результаты — [validation.json](validation.json).
Неизвестные зарубежные CDN и API российского приложения могут потребовать
отдельного дополнения после проверки журнала соединений на телефоне.

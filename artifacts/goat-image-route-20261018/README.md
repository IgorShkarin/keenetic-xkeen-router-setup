# GOAT: сервер картинок через домашний VPN

18 октября 2026 года. Исходный симптом iPhone на домашнем Wi-Fi при выключенном
Happ: в Wants отображаются цены, но фотографии товаров отсутствуют.

В 21:38:59 МСК журнал роутера показывает `image.goat.com` через `direct`.
Две загрузки одного публичного контрольного JPEG напрямую остановились на
16 384 и 15 847 байтах из 37 191 и завершились таймаутами через 15 секунд.
Через выбранный домашний VPN тот же JPEG оба раза загрузился полностью:
37 191 байт за 0,172 и 0,171 секунды, HTTP 200, image/jpeg.
Это доказывает разницу путей для контрольного файла; не устанавливает
виновника ограничения и не подтверждает загрузку фотографий на iPhone.

Применено узкое правило [rule.json](rule.json): TCP к `image.goat.com`
для домашних redirect/tproxy и диагностического SOCKS идёт через существующий
балансировщик `home-priority`. UDP-политика сохранена. Исходный routing
и состояние API сохранены приватно; SHA-256 локальной и серверной копий совпал.

Кандидат проверен полным `xray run -test -confdir`: `Configuration OK`.
Семантическое сравнение подтверждает ровно одно добавленное TCP-правило;
остальные правила и балансировщики не изменены.
Вызов RoutingService применил полный routing с этим дополнительным фрагментом:
26 правил стали 27. Выбранный VPN сохранён, PID Xray не менялся, рестарта не было.
Для вызова API заданы `XRAY_LOCATION_ASSET=/opt/etc/xray/dat` и `--timeout=20`:
клиент компилирует GeoSite до RPC, поэтому стандартных трёх секунд оказалось мало.
Два предшествующих неуспешных вызова оставили исходные правила и работающий процесс;
после них проверены исходный файл, 26 правил API и состояние менеджера.

После применения диагностический SOCKS **10808** использовал общую политику
маршрутизации, а не принудительный VPN-порт 10809. Тот же JPEG дважды получен
полностью за **0,240 и 0,310 секунды**. SHA-256 обоих файлов совпал с полной
контрольной картинкой. Активная конфигурация повторно прошла `Configuration OK`.
Подробные обезличенные результаты: [verification.json](verification.json).

Исходный backup: `/opt/var/backups/goat-image-route-20261018T1845Z/`.
Локальная копия: игнорируемый `private-backups/goat-image-route-20261018/`.
Для отката восстановить `05_routing.before.json` в активный routing и загрузить
его целиком через RoutingService под общим `/tmp/home-vpn-auto.lock`, сохранив
текущий выбор балансировщика. `rule.json` документирует только добавленный
фрагмент; при применении использовался полный кандидат маршрутизации.

На телефоне требуется полностью закрыть и открыть GOAT при выключенном Happ,
чтобы создать новые соединения. Появление фотографий на самом iPhone пока
не подтверждено владельцем.

Источник контрольного файла: [официальная карточка GOAT](https://www.goat.com/sneakers/air-jordan-9-retro-og-space-jam-2026-hv4794-106).
Снимки экрана пользователя, его wishlist и полная конфигурация роутера
в публичный пакет не копируются.

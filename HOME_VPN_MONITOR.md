# Диагностика и возврат на личный VPN

Приоритет: личный VPS AlexHost → действующая цепочка Blanc → Amnezia.
Менеджер `/opt/sbin/home-vpn-auto` запускается существующим cron раз в минуту.

Проверки используют SOCKS 10809, принудительно направленный через VPN:
YouTube `generate_204` и Cloudflare trace. В журнале есть HTTP-код,
код ошибки curl, время TCP/TLS/всего запроса и выходной IP.
Один недоступный сайт не отключает весь VPN. Два последовательных цикла,
в которых оба сайта недоступны, вызывают переход на резерв. Ответ trace
с неправильным IP также считается ошибкой личного маршрута.

На резерве раз в минуту запускается короткий изолированный Xray на 10818.
Он не меняет рабочий маршрут. Для возврата нужны две успешные проверки
в отдельных циклах, оба сайта и подтверждённый IP `185.234.9.26`.
После ухода на резерв действует пауза возврата две минуты.
Конфигурация проверяется перед переключением; после него снова проверяется
фактический выход. Неудачный возврат откатывается. Неработающий Blanc
передаётся существующему менеджеру резервов.

## Журналы

`/opt/var/log/home-vpn/rolling/` — скользящие последние 15 минут:
по минуте до 48 КиБ error.log, 16 КиБ access.log, 8 КиБ результатов проверок
и небольшой снимок состояния. Это ограниченные фрагменты, а не полный
захват всего трафика. Старые минуты удаляются при следующем цикле.

Перед переключением/попыткой восстановления пулов этот буфер сохраняется
в `/opt/var/log/home-vpn/incidents/*.log.gz`. Результат операции — соседний
файл `.result`. При неудачном возврате отдельный снимок сохраняется до отката.
Хранятся не более восьми эпизодов и суммарно не более 8 МиБ архивов.
Общий объём диагностики обычно меньше 10 МиБ. До первых 15 минут работы
архив содержит только уже накопленные записи.

Исходные логи Xray ограничиваются раз в минуту: error.log до 256 КиБ,
access.log до 128 КиБ. Между проверками они могут временно превысить лимит.
Сохраняется inode открытого Xray файла; параллельная запись во время
усечения может потерять несколько строк. Снимок снимается до усечения.
Конфиги, ключи и тела пользовательских запросов в архив не копируются;
сетевые логи содержат локальные адреса и посещаемые домены и остаются приватными.

```sh
ssh root@192.168.1.1 /opt/sbin/home-vpn-auto status
ssh root@192.168.1.1 'ls -lt /opt/var/log/home-vpn/incidents'
ssh root@192.168.1.1 'gzip -dc /opt/var/log/home-vpn/incidents/ИМЯ.log.gz'
```

Исходники: `tools/home-vpn-auto.sh`, `tools/home-vpn-log.sh`.
Проверка: `python3 tools/test_home_vpn_auto.py -v`.
Установка: `sh tools/install-home-vpn-monitor.sh`.
Установка сохраняет точный backup скриптов, состояния, активного outbound,
cron и log-конфига на самом роутере, проверяет конфигурацию и не перезапускает Xray.
Cron и маршруты установки не изменяются.

Для отката остановить запуск менеджера через его lock, восстановить скрипты
из выданного каталога backup (старый менеджер не использует новый журнал),
освободить lock. Outbound и состояние восстанавливать только если нужен
откат именно маршрута, затем проверить конфигурацию и перезапустить только XKeen.

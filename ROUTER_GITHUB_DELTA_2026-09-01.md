## Почему откат к GitHub сейчас опасен

1. GitHub не восстановит прошивку или startup-config.
2. Публичный outbound — шаблон; без приватного `04_outbounds.json` VLESS не поднимется.
3. Будут потеряны полезные изменения после 17 июля, прежде всего `cdntogo.net → direct`, Fastly IP, BlueSystem, Bankcomat и Stripe/Link.
4. Текущая неисправность возникает раньше загрузки Xray: USB/OPKG размонтируется после завершения Dropbear. Замена routing-файла эту причину не исправит.

## Безопасный порядок продолжения

1. Не монтировать `OPKG` повторно вслепую и не восстанавливать публичный GitHub-файл поверх USB.
2. Сохранить текущие `firmware` и `startup-config` версии 5.1.4 до обсуждения downgrade.
3. Найти причину немедленного завершения Entware Dropbear и автоматического размонтирования `OPKG`.
4. После безопасного доступа к USB скопировать только для чтения:
   - `/opt/etc/xray/configs/05_routing.json`;
   - список `05_routing.json.bak-*`;
   - релевантные startup-логи Entware/XKeen.
5. Сравнить live `05_routing.json` с `5108d43`, исключая секретный `04_outbounds.json`.
6. Подготовить отдельный санитизированный Git-коммит с подтверждёнными post-2026-07-17 правилами. Push выполнять только по отдельной просьбе.
